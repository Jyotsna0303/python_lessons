# python_lessons

Difference between python 2 and python 3 version?
Backward compatibility issues: Python 2 scripts may not run in Python 3 without modification.

Python 2 print "Hello" (without parentheses)
Python 3 print("Hello") (with parentheses)

Python 2 = 5 / 2 = 2 (floor division)
Python 3= 5 / 2 = 2.5 (true division)

Python 2 = Strings are ASCII by default
Python 3= Strings are Unicode by default (str is Unicode)

Python 2 = dict.keys() returns a list 
Python 3= dict.keys() returns a view object (iterable)
